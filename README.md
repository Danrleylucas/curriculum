## Destaques técnicos

- **HTML, CSS e JavaScript puros** — arquivo único, sem dependências ou frameworks
- **Segurança aplicada no código:**
  - Content Security Policy (CSP) contra XSS e injeção de conteúdo
  - Proteção anti-clickjacking
  - `rel="noopener noreferrer"` em links externos (contra tabnabbing)
  - `textContent` em vez de `innerHTML` (previne injeção de HTML)
  - Contato por links diretos: sem formulário = sem superfície de ataque em site estático
- **Resiliência:** cada funcionalidade JavaScript é isolada — se uma falhar, as demais continuam (graceful degradation); o conteúdo nunca depende de script para aparecer
- **Animações em canvas** com tema de segurança (chuva Matrix, radar de monitoramento, rede de nós, código binário), pausadas fora da tela para economizar bateria
- **Acessibilidade:** respeita `prefers-reduced-motion`, atributos ARIA e navegação por teclado
- **Responsivo:** ajustado para celular (100svh, alvos de toque) e desktop (Safari incluso)
